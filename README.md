# HIE-Blockchain
Healthcare Information Exchange using Blockchain

## 📌 Overview
This project implements a **Healthcare Information Exchange (HIE)** platform powered by **Blockchain**.  
It ensures secure, decentralized storage and retrieval of patient and doctor information.

The system consists of:
- **Smart Contracts** (`/contracts`) for patient and doctor data.
- **Web Frontend** (`/web`) – the original HTML/CSS/JS prototype.
- **Mobile App** (`/mobile-app`) – React Native (Expo) application with navigation, forms, and blockchain integration.
